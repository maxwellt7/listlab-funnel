# Fonts for the landing page

The Latin subsets of the three typefaces the reviewed page draft loaded from Google Fonts, kept here so the
page serves them itself (no request to Google, no layout shift while they load).

| File | Typeface | What it covers |
| --- | --- | --- |
| `inter-latin.woff2` | Inter 4.001 | variable weight; the page uses 400–700 |
| `newsreader-latin.woff2` | Newsreader 1.003 | variable weight and optical size; the page uses 400 and 600 |
| `newsreader-latin-italic.woff2` | Newsreader 1.003 italic | regular weight, variable optical size |
| `caveat-latin.woff2` | Caveat 2.000 | SemiBold (600), for the hand-lettered "Experienced investor?" |

Source: the files served for
`https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=Newsreader:ital,opsz,wght@0,6..72,400;0,6..72,600;1,6..72,400&family=Caveat:wght@600`
(Inter v20, Newsreader v26, Caveat v23), downloaded 2026-11-11.
